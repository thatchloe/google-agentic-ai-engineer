# Google Agentic AI Engineer

Projects for the Google Agentic AI Engineer program.

## Projects

- [Legal Intelligence AI System](legal-intelligence/) - a multi-agent legal analysis service for
  LexiMind Solutions built on Gemini and Vertex AI. Three expert personas analyze a complaint in
  sequence, passing context between sections, with quality validation and automatic retries. See
  the [final report](legal-intelligence/starter/final_report.md) for sample output.
- [Project 3: Taking Wing - Building an Agentic Bird Brain](project-3/) - a customer-support
  agent for Betty's Bird Boutique built with Google's Agent Development Kit (ADK) on Vertex AI.
  It answers product-price questions from MySQL through the MCP Toolbox, store questions from
  PDFs indexed in Vertex AI Search, and general bird questions with Grounding with Google
  Search, and it never takes orders. See the [project README](project-3/README.md) for setup,
  testing and the submission checklist.
